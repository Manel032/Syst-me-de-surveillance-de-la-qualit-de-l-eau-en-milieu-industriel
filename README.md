# Syst-me-de-surveillance-de-la-qualit-de-l-eau-en-milieu-industriel
Le système vise à surveiller la qualité de l'eau dans une installation industrielle pour détecter la présence de contaminants, altérations de température et niveaux de l’acidité, pouvant affecter les processus industriels. Il mesure plusieurs paramètres critiques afin d'assurer la sécurité et la conformité des eaux utilisées
